# badge3-wattson

Saved right after earning the third badge (Dynamo Badge) from Wattson in
Mauville Gym, just before the DLC's start trigger (talk to Mr. Briney after
Wattson). Tracked in #8.

Put the save here as **`badge3-wattson.sav`**.

## How it was made

1. Play an unpatched Pokémon Emerald (US), BPEE rev 0 ROM in mGBA.
2. Beat Wattson and receive the Dynamo Badge.
3. Save from the in-game Start menu (not an emulator save state).
4. Note the values below, then close the game so the `.sav` is written.
